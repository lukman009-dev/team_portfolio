# team_portfolio

Simple static team portfolio template for learning Git & GitHub collaboration.

How to use:
1. Clone the repo:
   git clone git@github.com:lukman009-dev/team_portfolio.git
2. Create a branch for your task:
   git checkout -b feature/yourname/section
3. Make changes, then:
   git add .
   git commit -m "Add X"
   git push -u origin feature/yourname/section
4. Open a Pull Request on GitHub.

Deploy: Enable GitHub Pages in repo Settings → Pages → Branch: main / Folder: / (root).

Contributing:
- Create an issue for each task.
- Link PRs to issues with "Closes #N".
- Keep changes small and focused.

Replace member images in assets/images/ or remove the <img> tags if you don't have images yet.
